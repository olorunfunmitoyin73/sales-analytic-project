# sales-analytic-project
This project showcase sales performance of a company that deals in edible items.
### Project Overview
This data analytics project aims to showcase sales performance of a company producing consumable items for a period of 2 years (2015 & 2016 respectively). By analyzing the fact table after every connections have been created, we seek to display trends through graphical illustrations, showcase performance of each sales persons and also display the KPIs in line with the necessary slicers.
